# Security Policy

[简体中文](SECURITY.zh-CN.md)

## Supported versions

Security fixes are provided for the latest published GitHub Release. The current supported release is `v2.0.1`; older releases and unreleased commits are not supported.

## Report a vulnerability

Email **s-qin21@outlook.com** with the subject `[SECURITY] aws-region-select-tool`. Do not open a public issue for a vulnerability that could expose users, systems, credentials, or sensitive report data.

Please include:

- affected version or commit;
- impact and affected CLI mode;
- minimal reproduction steps or proof of concept;
- relevant PowerShell and Windows versions; and
- sanitized console output or JSON excerpts, if useful.

Remove credentials, tokens, private keys, personal paths, and unnecessary IP addresses before sending. The maintainer will review the report and coordinate disclosure and remediation when applicable. AWS service or infrastructure vulnerabilities should also be reported through the appropriate AWS security channel.
